## What is Recipe Roulette?
Recipe Roulette is a fun and interactive random meal generator.

Users can choose a cuisine, click “Get Random Recipe”, and a recipe is displayed in a pop-up modal complete with an image and a link to the full recipe. If the recipe doesn’t appeal, users can close the pop-up and try again!

## Features
- Select a cuisine type  
- Generate a random recipe with a single click  
- Display recipe details in a pop-up modal  
- Includes an image and link to the full recipe  
- Simple and engaging user experience  

## Technologies Used
- **JavaScript** – Application logic and user interaction  
- **HTML** – Structure and layout  
- **CSS** – Styling and modal layout  

### JavaScript Concepts Practiced
- Working with a flexible dataset
- Using `Math.random()` to select random items from an array  
- Handling user interactions and events  
- Dynamic DOM manipulation
